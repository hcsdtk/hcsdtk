## 👋 你好，我是 Chasen

一名在深圳工作的开发者。过去专注微信小程序与前端工程化，现在把更多精力放在 **AI Agent、内容工作流和本地优先的创作工具** 上。

我喜欢从一个具体、真实的问题出发，把它做成小而完整的产品：能运行、能交付，也能被别人继续使用和改造。

> I think, so I am. 更重要的是：**I build, so ideas become real.**
